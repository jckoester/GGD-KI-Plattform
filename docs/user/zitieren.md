# KI-Ergebnisse zitieren

Wer Ergebnisse aus dieser Plattform in einer GFS, im Seminarkurs oder in einer Facharbeit
verwendet, muss das **kenntlich machen** — genau wie bei jeder anderen Quelle. Dazu gehören
üblicherweise das Werkzeug, das **Modell**, das geantwortet hat, das **Datum** und die
**eigene Eingabe**.

Alle diese Angaben hält die Plattform bereit. Du musst sie nicht abschreiben.

> **Welche Zitierweise gilt, sagt deine Schule oder deine Lehrkraft.** Die Vorgaben
> unterscheiden sich zwischen Fächern und Arbeitsformen. Die Plattform liefert die
> **Angaben** — in welche Form du sie bringst, steht in deiner Vorgabe.

---

## Im Chat

Unter jeder Antwort steht ein kleiner Knopf **„Herkunft"**. Ein Klick zeigt:

```
Text: gpt-oss-120b
Erzeugt am 29.08.2026, 07:31
```

Darunter liegt **„Angaben zum Zitieren kopieren"**. Das legt einen fertigen Textbaustein in
die Zwischenablage:

```
ki@schule, Modell gpt-oss-120b, abgerufen am 29.08.2026, 07:31
Eigene Eingabe: „Erkläre mir bitte den Wasserkreislauf für eine Klassenarbeit in Klasse 7."
```

## Bei Bildern

Ein Bild hat eine **eigene** Herkunft — es stammt aus einem anderen Modell als der Text
drumherum. Beides steht deshalb getrennt:

```
Text: gpt-oss-120b
Bild: FLUX.2-klein-4B
```

> **Der Bild-Prompt ist nicht deine Eingabe.** Du hast vielleicht „zeichne mir dazu ein
> Schema" geschrieben — die ausführliche Bildbeschreibung hat das Sprachmodell daraus
> gemacht. Im Textbaustein steht das ausdrücklich dabei:
>
> ```
> Bild erzeugt mit FLUX.2-klein-4B. Bild-Prompt (vom Sprachmodell formuliert):
> „Ein Schema des Wasserkreislaufs mit beschrifteten Pfeilen"
> ```
>
> Diesen Prompt als eigene Formulierung auszugeben wäre eine Falschangabe.

## In der Bibliothek

Unter jedem Eintrag steht, womit er erzeugt wurde („Erzeugt mit `FLUX.1-schnell`"), und es
gibt einen Knopf **„Zitieren"** mit demselben Textbaustein.

Das ist der Ort, an dem du nachsiehst, wenn du ein Bild aus der Bibliothek in ein Dokument
übernimmst: Die Angabe bleibt am Artefakt, auch wenn der Chat längst gelöscht ist.

## In exportierten Dokumenten

Exportiert deine Schule Arbeitsblätter mit **Herkunftszeile** (eine Einstellung, die die
Administration setzt), steht am Ende jedes PDF-, Word- oder ODT-Exports:

```
Erstellt mit ki@schule · Modell gpt-oss-120b · 29.08.2026
```

Sie erscheint nur bei Dokumenten, die aus einer KI-Antwort entstanden sind — was du selbst
geschrieben hast, bleibt unmarkiert.

---

## Warum manchmal nichts dasteht

Bei älteren Inhalten fehlt die Angabe. Das ist kein Fehler: Sie wird erst seit dem Update
vom 29.08.2026 mitgeschrieben, und für alles davor lässt sie sich nicht nachträglich
ermitteln — welches Modell damals gearbeitet hat, weiß niemand mehr. Ein geratener Wert
wäre in einer Quellenangabe schlimmer als eine Lücke.

Dasselbe gilt für Diagramme und Dokumente, die du aus einer **alten** Konversation
speicherst.
